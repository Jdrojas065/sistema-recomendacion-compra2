¿Cómo se calculan estos valores?

Método tradicional (promedio móvil): se calcula dividiendo la cantidad total vendida de este producto entre el número de ventas registradas en los últimos 6 meses. Es un cálculo estadístico simple, sin inteligencia artificial (RF08).

Machine Learning (Random Forest): modelo entrenado en un servicio Python independiente. Recibe como entrada el día de la semana, el mes, la rotación del producto, el stock actual, el promedio tradicional recién calculado, la categoría y los días desde la última venta — y combina estas variables de forma no lineal para generar su propia proyección (RF09).

Nota de transparencia: el modelo se entrenó con un conjunto de datos sintético (generado para simular patrones de venta realistas), no con el historial real de un negocio en producción. Es una decisión consciente para esta entrega académica; los valores de Machine Learning deben interpretarse como demostración del funcionamiento del pipeline completo (Spring Boot ↔ servicio Python ↔ modelo), no como una predicción con validez estadística garantizada todavía.
